# Temperature Converter



\## Purpose

A small Python program that converts a temperature from Celsius to Fahrenheit.

Made for CS-110 Lab 7 to practise Git and GitHub.



\## How to run

python temperature\_converter.py



\## Example

Input:  Temperature in Celsius: 37

Output: Fahrenheit: 98.6
